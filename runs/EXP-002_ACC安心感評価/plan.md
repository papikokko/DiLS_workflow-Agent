# DS試験計画書 — EXP-002

**案件ID：** EXP-002　**案件名：** ACC安心感・操作性評価
**作成日：** 2026-05-07　**ステータス：** 計画中

---

## 1. 試験目的

新しいACCシステムがドライバーに安心感・操作性を与えるかを定量的に評価する。
特に高速追従・合流場面でのシステム介入時の体感品質を検証する。

## 2. 試験構成

| 項目 | 内容 |
|------|------|
| 使用設備 | DiLS-03（Motion Platform搭載）+ DiLS-05 ログ連携 |
| 走行シナリオ | A：高速追従走行 / B：合流走行 |
| 被験者数 | 10名（ACC経験者5名・未経験者5名、20〜50代） |
| 取得データ | アンケート（5段階）/ 介入操作ログ |
| 実施期間 | 2026-05-14〜15（予定） |

## 3. 合否判断基準

| 指標 | 合格基準 |
|------|----------|
| アンケート平均スコア | 4.0点以上（全設問平均） |
| 介入操作回数 | 3回以内／セッション |
