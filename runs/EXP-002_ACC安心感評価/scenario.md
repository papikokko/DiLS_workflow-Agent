# 試験シナリオ — EXP-002

> 参照元：TEST-2025-031（感性評価構成）・TEST-2024-098（合流シナリオ）を流用・修正

## シナリオA：高速追従走行

| 項目 | 設定値 |
|------|--------|
| 走行速度 | 80〜100km/h |
| 走行時間 | 約10分 |
| 先行車速度 | 70〜90km/h（変動あり） |
| ACCイベント | 先行車減速による自動追従制御（3回） |
| 被験者課題 | 速度維持走行・手放し操作なし |
| 再現方式 | 再生ファイル統制（被験者間で同一条件） |

**検証ポイント：** ACCが先行車に追従する際の制動感・加速感の自然さ、介入の違和感

---

## シナリオB：合流走行

| 項目 | 設定値 |
|------|--------|
| 走行速度 | 60〜80km/h（合流加速含む） |
| 走行時間 | 約8分 |
| 合流イベント | 本線への合流加速支援（2回） |
| ACCイベント | 合流後の先行車捕捉・速度調整（2回） |
| 被験者課題 | ハンドル保持・合流操作 |
| 再現方式 | 再生ファイル統制 |

**検証ポイント：** 合流時のACC制御介入タイミング・加速支援の安心感

---

## 実施順序

奇数番の被験者はA→B、偶数番はB→Aの順で実施（順序効果を排除）

---

## アンケート設問

| 設問 | 測定内容 | 形式 |
|------|----------|------|
| Q1 ACCの動きに安心できた | 総合安心感 | 5段階 |
| Q2 加速・減速のタイミングが自然だった | 制御の自然さ | 5段階 |
| Q3 システムを信頼して任せられた | 信頼感 | 5段階 |
| Q4 介入時に驚きや不快感があった | 違和感（逆転項目） | 5段階 |
| Q5 このACCを実際のクルマで使いたい | 採用意向 | 5段階 |
| Q6 気になった点・改善してほしい点 | 自由記述 | 記述 |

> ※ Q4は逆転項目（スコアが低いほど良好）。集計時に反転処理を実施。
> ※ シナリオA・B終了後にそれぞれ回答（記憶混同を防ぐため）
