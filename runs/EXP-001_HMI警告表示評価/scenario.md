## シナリオA：市街地走行

| 項目 | 設定値 |
|------|--------|
| 走行速度 | 30〜50km/h |
| 走行時間 | 約10分 |
| 警告発令 | 走行開始3分後（2回） |
| 被験者課題 | 通常走行操作 |

## シナリオB：高速道路走行

| 項目 | 設定値 |
|------|--------|
| 走行速度 | 80〜100km/h |
| 走行時間 | 約8分 |
| 警告発令 | 走行開始2分後（2回） |
| 被験者課題 | 速度維持走行 |

## アンケート設問

| 設問 | 形式 |
|------|------|
| Q1 警告表示に気づきやすかったですか | 5段階 |
| Q2 警告の意味がわかりましたか | 5段階 |
| Q3 警告のタイミングは適切でしたか | 5段階 |
| Q4 走行への影響（ストレス）はありましたか | 5段階 |
| Q5 全体として使いやすかったですか | 5段階 |
| Q6 気になった点があれば教えてください | 自由記述 |

## 実施順序

奇数番の被験者はA→B、偶数番はB→Aの順で実施（順序効果を排除）
