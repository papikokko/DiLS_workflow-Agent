# 試験計画 — EXP-001 HMI警告表示の視認性評価

> 参照元：TEST-2025-014のシナリオ構成、validation_knowhow.md

## 1. 目的

新しいHMI警告表示が走行中のドライバーに正しく認識されるか確認する。

## 2. 評価対象・環境

| 項目 | 内容 |
|------|------|
| 対象機能 | HMI警告表示（新デザイン） |
| 評価環境 | DiLS-02（Eye Tracker・HMI表示設備あり） |
| 走行シナリオ | 市街地走行 / 高速道路走行 |
| 被験者数 | 12名（20〜50代、普通免許保有） |

## 3. 取得データ

| データ | 取得方法 | 精度 |
|--------|---------|------|
| 反応時間 | DiLSシステムログ | 100ms以下 |
| 視線ログ | Eye Tracker（DiLS-02搭載） | 60Hz |
| アンケート | シナリオ後に実施 | 5段階評価+自由記述 |

## 4. 合否判断基準

| 指標 | 目標値 |
|------|--------|
| 反応時間（市街地） | 2秒以内 |
| 反応時間（高速道路） | 1.5秒以内 |
| アンケート平均 | 4.0点以上（5段階） |

## 5. スケジュール

| フェーズ | 内容 | 期間 |
|---------|------|------|
| 準備 | 被験者募集・DiLS予約 | 2週間 |
| 予備実験 | 2名で手順確認 | 1日 |
| 本実験 | 12名（1名90分） | 3日 |
| 分析・報告書 | データ整理・作成 | 5日 |
