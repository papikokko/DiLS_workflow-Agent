# DS業務AIエージェント活用 デモ概要

## デモのメッセージ

> **DS運営担当者は、AIエージェントと協働することで、  
> 過去資料の検索・計画書作成・報告書ドラフト作成の時間を大幅に削減できる。**

---

## Before / After

### Before（現状）

| 業務 | 現状の課題 |
|------|---------|
| テスト受付 | 依頼内容が曖昧なまま進んで後で手戻り |
| 類似テスト検索 | 過去資料を手動で探すのに時間がかかる |
| DiLS選定 | 担当者の経験に依存している |
| 試験計画作成 | ゼロから作成しており非効率 |
| アンケート集計 | Excelで手作業、再利用されない |
| 報告書作成 | フォーマットが統一されておらず品質にばらつき |

### After（AIエージェント活用後）

| 業務 | AIエージェントの支援 |
|------|------------------|
| テスト受付 | 不足情報を自動で指摘・確認質問を生成 |
| 類似テスト検索 | 過去テストDBからスコア付きで自動提示 |
| DiLS選定 | 設備適合度スコアで客観的に推薦 |
| 試験計画作成 | 過去テストを流用してドラフトを自動生成 |
| アンケート集計 | 自動集計・可視化・傾向分析 |
| 報告書作成 | ドラフトを自動生成・参照根拠を明示 |
