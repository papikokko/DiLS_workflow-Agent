# DS業務AIエージェント検証 デモ

## このデモで解決したいDS業務課題

DS運営業務では、過去テスト・DiLS構成・シナリオ・アンケート・報告書が蓄積されている。  
しかし、依頼を受けたときに以下を人が都度探して判断している。

- どの過去テストを参考にするか
- どのDiLSを使うか
- どのシナリオを流用するか
- 報告書に何を書くか

このデモでは、**AIエージェントがこれらを一気通貫で支援するイメージ**を具体的に見せる。

---

## 対象業務範囲

テスト受付 → 要求理解 → 類似テスト検索 → DiLS推薦 → 試験計画作成 → シナリオ作成 → 実行記録 → アンケート集計 → 報告書ドラフト作成

---

## 起動方法

```bash
# 依存関係のインストール
pip install -r requirements.txt

# アプリ起動
streamlit run app.py
```

ブラウザが自動で開きます。開かない場合は http://localhost:8501 にアクセスしてください。

---

## デモシナリオ

**テスト依頼例：HMI警告表示の視認性評価（EXP-001）**

> 新しい警告表示が走行中のドライバーに認識されやすいか確認したい。  
> 反応時間・視線ログ・アンケートで評価したい。

1. **タブ1「受付・要求理解」** で依頼内容を確認し、AIが不足情報を指摘するのを見せる
2. **タブ2「類似テスト・DiLS推薦」** で過去テストTop3とDiLS-02の推薦を見せる
3. **タブ3「試験計画・シナリオ」** でAIが生成した計画書・シナリオを見せる
4. **タブ4「実行記録・アンケート」** で集計結果をダッシュボードとして見せる
5. **タブ5「報告書・成果物」** でドラフト報告書の生成・保存を見せる

---

## 画面説明

| タブ | 目的 | 表示内容 |
|------|------|---------|
| 受付・要求理解 | 依頼を構造化する | 依頼内容、不足情報、AIの確認質問 |
| 類似テスト・DiLS推薦 | 過去知見と設備判断を見せる | 類似テストTop3、推奨DiLS、理由 |
| 試験計画・シナリオ | 作業代替イメージを見せる | plan.md・scenario.md生成 |
| 実行記録・アンケート | 実行後データ活用を見せる | execution_log、questionnaire集計 |
| 報告書・成果物 | 最終アウトプットを見せる | report_draft.md、output保存 |

## 顧客に見せる価値

> **担当者は、過去資料探索やゼロからの資料作成ではなく、  
> AIが提示した候補・計画・報告書ドラフトを確認し、  
> 依頼者との合意形成や最終判断に時間を使える。**

## 本番化の方向性

初回デモはローカルアプリだが、将来的には以下へ拡張できる。

- SharePoint上の過去資料・報告書との連携
- Teamsトランスクリプトからの自動知見抽出
- DiLS構成・予約情報との連携
- 報告書テンプレートへの自動反映
- Copilot StudioやAzure OpenAI等による社内運用化
